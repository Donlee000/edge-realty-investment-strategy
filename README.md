# Edge Realty Investment Strategy

## Project overview

An independent portfolio project inspired by Edge Realty’s public
property offering, exploring how an AED 250 million budget could be
allocated across residential and institutional properties in selected
UAE locations from 2026 to 2030.

## Main question

Which combination of locations, property types and acquisition or
development strategies could deliver the strongest projected net
rental income and total return by 2030 within the investment budget?

## Investment strategies

- Residential: acquire properties to generate rental income.
- Institutional: acquire or develop facilities leased to operators,
  including schools, universities, nurseries and specialist academies.
- Mixed portfolio: combine residential and institutional investments.

Each strategy uses the same AED 250 million budget, with unspent
cash and future capital commitments tracked explicitly.

## Planned analysis

- Compare acquisition and development costs.
- Estimate rental income after vacancy and landlord expenses.
- Account for construction periods and rental start dates.
- Compare conservative, base and optimistic scenarios.
- Evaluate projected returns, including hypothetical resale values.
- Present portfolio comparisons in an interactive Power BI dashboard.

## Planned tools

- Python for data extraction, cleaning and validation.
- SQL for data modelling and analysis.
- Power BI for interactive reporting.
- Git and GitHub for version control and documentation.

## Data and assumptions

The starting workbooks contain residential and institutional scenarios.
Many records are fictional, and adjusted prices, rents and development
costs are illustrative assumptions rather than verified market values.

Scenario results will be distinguished from observed market evidence.
Institutional income represents property rent, not tuition fees or
institutional operating profits.
